# Label Guide

| Label | Meaning |
| --- | --- |
| `bug` | Customer reports a defect, crash, outage, security or billing problem. |
| `enhancement` | Customer requests a new capability or improvement. |
| `priority:P1` | Critical: data loss, security, billing, lockout, total outage. |
| `priority:P2` | Major: crash, error, broken feature, severe slowness. |
| `priority:P3` | Minor: enhancement requests and non-critical items. |
